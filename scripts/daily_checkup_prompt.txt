## What to check

Run these from /home/joey/equity_v2_4 with `source .venv/bin/activate` first:

```
python experiments/run_equity_paper_step.py --config config/settings_equity_paper_yfinance_simpletrend.yaml status
python experiments/run_equity_paper_step.py --config config/settings_equity_paper_yfinance.yaml status

systemctl list-timers 'equity*' --all

journalctl -u equity-paper-yfinance-simpletrend.service -u equity-paper-yfinance.service -u equity-paper-calls.service --since "-24 hours" --no-pager | grep -iE "error|traceback|exception" || true
curl -s -o /dev/null -w "%{http_code}" http://localhost:8501
```

Evaluate what you find against these specific failure patterns (all have
happened before on this system, so take them seriously, don't just eyeball
"looks fine"):

- **Stuck pending_entry**: an open_position with status "pending_entry" and
  entry_price null, where last_processed_bar_date is more than 1 trading day
  old. This means a signal fired but never filled. This IS safe to fix
  yourself: re-run `... step` for that deployment's config, then re-check
  status to confirm it advanced to status "open" with a real entry_price.
  If it's still stuck after that, flag it in the email as unresolved -- don't
  loop retrying.
- **Halted with no clear reason**: any deployment showing "halted": true that
  you don't have context for (Ridge being halted was once a deliberate
  choice, documented in CLAUDE.md -- if it's halted, check whether that looks
  intentional or not before flagging it as a problem). Do NOT resume a halted
  deployment yourself -- that's a decision only Joey makes. Just report it clearly.
- **Stale timer**: a timer whose LAST PASSED / recent activity doesn't match
  its schedule (e.g. a daily timer that hasn't fired in >36 hours on a weekday).
- **Errors in the last 24h of journalctl logs** for any of the three services.
- **Dashboard down**: btc-dashboard.service not active, or the curl check
  above doesn't return 200.
- **current_price never refreshing**: if a stock bot's open_position has
  current_price_at older than ~1 hour during market hours (roughly 13:30-20:00
  UTC weekdays), the quote-refresh timer may be broken.

Do not modify any config file, strategy YAML, or code. Do not touch git. Do

  and unrealized % if available, count of completed trades, and one line on

  keep this to 1-2 lines per bot, not a full dump.

  did about it, and the confirmed result.

  above so it doesn't get missed.

  boilerplate for every single check.

should be short -- a few lines, not a wall of "checked X, fine" bullet points.
